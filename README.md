# Tic-Tac-Toe Multiplayer

A small learning project built with React and Node.js. Play against the computer
or invite a friend to a real-time multiplayer game using a shared lobby link.

Classic games support 3x3, 4x4 and 5x5 boards. Chaos is an online 5x5 mode
with power-ups.

https://tictactoewebgame-server.onrender.com
